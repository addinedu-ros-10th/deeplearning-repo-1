Notify WebSocket 수동 테스트

큐잉 API 예시(curl)

아래 예시에서 recipients에 위 user_id를 사용하세요.

curl -X POST "$BASE_URL/api/v1/notify/queue" \
-H "Content-Type: application/json" \
-d '{
  "kind": "info",
  "severity": "green",
  "title": "Hello",
  "body": "From curl",
  "data": { "k": 1 },
  "recipients": ["<UUID>"],
  "channel": "websocket"
}'

환경 변수(디스패처/WS): NOTIFY_ENABLE=true, NOTIFY_DISPATCH_ENABLE=true, NOTIFY_WS_ENABLE=true
