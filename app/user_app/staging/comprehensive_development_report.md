## 📊 프로젝트 개요

### **프로젝트 목표**
노인 돌봄 서비스를 위한 사용자 친화적인 음성 인터페이스 앱 개발

### **핵심 가치**
- **접근성**: 직관적이고 큰 버튼으로 노인 사용자 친화적
- **실시간성**: WebSocket을 통한 즉시 알림 및 음성 응답
- **개인화**: 사용자별 맞춤형 메시지 및 관계자 네트워크
- **안정성**: STT/TTS 충돌 방지 및 강화된 에러 핸들링

## 🏗️ 아키텍처 현황

### **기술 스택**
- **프레임워크**: Flutter 3.x
- **상태 관리**: Provider 패턴
- **네비게이션**: GoRouter
- **HTTP 클라이언트**: Dio
- **음성 처리**: speech_to_text, flutter_tts
- **실시간 통신**: WebSocket
- **로컬 저장소**: SharedPreferences

### **서버 연동**
- **App Server**: 사용자 관리 및 인증 (`ec2-13-125-249-77`)
- **DL Server**: 알림 시스템 및 메시징 (`ec2-43-201-96-23`)
- **OpenAI API**: AI 응답 생성 (`api.openai.com`)

## 🎯 구현된 주요 기능

### **1. 인증 시스템** ✅
- **자동 로그인**: 첫 번째 사용자 자동 로그인 (비밀번호: 1234)
- **로그인 정보 기억**: SharedPreferences를 통한 지속적 로그인 상태 유지
- **사용자 선택사항 저장**: "기억하기", "자동 로그인" 옵션 유지

### **2. 음성 인터페이스** ✅
- **STT (Speech-to-Text)**: 실시간 음성 인식
- **TTS (Text-to-Speech)**: AI 응답 음성 출력
- **OpenAI 연동**: GPT-4o-mini 모델 활용
- **충돌 방지**: TTS 재생 중 STT 완전 비활성화
- **실시간 채팅**: 음성 입력 결과 즉시 표시
- **음파형 UI**: 인터랙티브한 시각적 피드백

### **3. 사용자 관리** ✅
- **사용자 목록**: API를 통한 사용자 목록 조회
- **사용자 상세 정보**: 프로필 정보 및 관계자 네트워크
- **인적 자원 네트워크**: 노드와 엣지가 유기적으로 연결된 관계도
- **관계자 정보**: 노드 클릭 시 관계자 상세 정보 표시

### **4. 알림 시스템** ✅
- **실시간 알림**: WebSocket을 통한 실시간 메시지 수신
- **알림 다이얼로그**: 새 알림 수신 시 별도 다이얼로그로 즉시 표시
- **사용자별 메시지 조회**: by-sender API를 통한 개인화된 메시지 필터링
- **메시지 전송**: REST API를 통한 메시지 전송
- **알림 목록**: 수신된 알림 목록 조회 및 관리

### **5. 긴급 신고 시스템** ✅
- **긴급 신고 화면**: 경고 메시지 및 진동 알림
- **취소 기능**: 신고 취소 버튼으로 메인 화면 복귀

### **6. UI/UX 개선** ✅
- **네트워크 시각화**: 노드와 엣지가 유기적으로 연결된 관계도
- **채팅 인터페이스**: 페이드아웃 효과가 있는 채팅 UI
- **반응형 디자인**: 다양한 화면 크기에 대응
- **직관적 네비게이션**: 명확한 버튼 배치 및 동작

## 🔧 해결된 주요 기술적 도전

### **1. STT/TTS 무한 회귀 문제**
- **문제**: AI 응답이 다시 STT로 입력되는 무한 반복 현상
- **해결**: TTS 재생 중 STT 완전 비활성화 로직 구현
- **결과**: 안정적인 음성 인터페이스 동작

### **2. 네트워크 UI 분리 문제**
- **문제**: 노드와 엣지가 시각적으로 분리되어 보임
- **해결**: CustomPainter와 Positioned 위젯 좌표 일치
- **결과**: 유기적으로 연결된 네트워크 시각화

### **3. 뒤로가기 버튼 오작동**
- **문제**: 사용자 상세 페이지에서 뒤로가기 불가
- **해결**: `context.push()` 사용으로 네비게이션 스택 관리
- **결과**: 정상적인 네비게이션 동작

### **4. CORS 정책 오류**
- **문제**: OpenAI API 호출 시 CORS 오류
- **해결**: API 엔드포인트 수정 및 에러 핸들링 개선
- **결과**: 정상적인 AI 응답 생성

### **5. 알림 표시 개선**
- **문제**: 새 알림이 목록에만 표시되고 즉시 확인하기 어려움
- **해결**: 알림 다이얼로그 구현으로 새 알림 즉시 표시
- **결과**: 사용자가 새 알림을 즉시 확인 가능

### **6. 사용자별 메시지 필터링**
- **문제**: 전체 메시지를 조회하여 개인화되지 않음
- **해결**: by-sender API를 통한 사용자별 메시지 조회
- **결과**: 로그인한 사용자에게 온 메시지만 표시
