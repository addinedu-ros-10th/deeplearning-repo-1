## 📋 프로젝트 개요

Flutter 기반의 음성 인터페이스 앱으로, 노인 돌봄 서비스를 위한 사용자 친화적인 UI/UX를 제공합니다.

---

## 🎯 주요 기능 구현 현황

### ✅ 완료된 기능

#### 1. **인증 시스템**
- **로그인 화면**: 첫 번째 사용자 자동 로그인 (비밀번호: 1234)
- **자동 로그인**: SharedPreferences를 통한 로그인 상태 유지
- **로그인 정보 기억하기**: 사용자 선택사항 저장
- **로그아웃**: 사용자 상세 페이지에서 로그아웃 가능

#### 2. **음성 인터페이스 (메인 화면)**
- **STT (Speech-to-Text)**: 실시간 음성 인식
- **TTS (Text-to-Speech)**: AI 응답 음성 출력
- **OpenAI API 연동**: GPT-4o-mini 모델 사용
- **STT/TTS 충돌 방지**: TTS 재생 중 STT 비활성화
- **실시간 채팅 UI**: 음성 입력 결과 실시간 표시
- **음파형 UI**: 인터랙티브한 시각적 피드백

#### 3. **사용자 관리**
- **사용자 목록**: API를 통한 사용자 목록 조회
- **사용자 상세 정보**: 프로필 정보 및 관계자 네트워크
- **인적 자원 네트워크**: 관계자들의 시각적 네트워크 표현
- **관계자 정보**: 노드 클릭 시 관계자 상세 정보 표시

#### 4. **알림 시스템**
- **DL 서버 연동**: `http://ec2-43-201-96-23.ap-northeast-2.compute.amazonaws.com`
- **실시간 알림**: WebSocket을 통한 실시간 메시지 수신
- **메시지 전송**: REST API를 통한 메시지 전송
- **알림 목록**: 수신된 알림 목록 조회 및 관리
- **사용자 ID 기반**: `10fa45f2-f375-41c9-a62a-093efcd01bd3` 사용자로 테스트

#### 5. **긴급 신고 시스템**
- **긴급 신고 화면**: 경고 메시지 및 진동 알림
- **취소 기능**: 신고 취소 버튼으로 메인 화면 복귀

#### 6. **UI/UX 개선**
- **네트워크 시각화**: 노드와 엣지가 유기적으로 연결된 관계도
- **채팅 인터페이스**: 페이드아웃 효과가 있는 채팅 UI
- **반응형 디자인**: 다양한 화면 크기에 대응
- **직관적 네비게이션**: 명확한 버튼 배치 및 동작

## 🔧 기술적 구현 사항

### **환경 변수 관리**
```dart
// DL 서버 설정
static String get dlBaseUrl {
  const String envValue = String.fromEnvironment('DL_BASE_URL');
  if (envValue.isNotEmpty) return envValue;
  final dotenvValue = _safeMaybeGet('DL_BASE_URL');
  if (dotenvValue.isNotEmpty) return dotenvValue;
  return 'http://ec2-43-201-96-23.ap-northeast-2.compute.amazonaws.com';
}
```

### **STT/TTS 충돌 방지**
```dart
// TTS 재생 중 STT 비활성화
if (_isTtsPlaying) return;

// TTS 완료 콜백
_ttsService.setCallbacks(
  onComplete: () {
    setState(() {
      _isTtsPlaying = false;
    });
  },
);
```

### **네트워크 시각화**

- **관계 타입 라벨**: 엣지 중앙에 관계 표시
- **인터랙티브**: 노드 클릭 시 상세 정보 표시

## 🐛 해결된 주요 이슈

### **1. 네트워크 UI 분리 문제**
- **문제**: 노드와 엣지가 시각적으로 분리되어 보임
- **해결**: 좌표 계산 일치 및 CustomPainter 개선
- **결과**: 유기적으로 연결된 네트워크 시각화

### **2. STT/TTS 무한 회귀**
- **문제**: AI 응답이 다시 STT로 입력되는 현상
- **해결**: TTS 재생 중 STT 비활성화 로직 구현
- **결과**: 안정적인 음성 인터페이스 동작

### **3. 뒤로가기 버튼 오작동**
- **문제**: 사용자 상세 페이지에서 뒤로가기 불가
- **해결**: `context.push()` 사용으로 네비게이션 스택 관리
- **결과**: 정상적인 네비게이션 동작

### **4. CORS 정책 오류**
- **문제**: OpenAI API 호출 시 CORS 오류
- **해결**: API 엔드포인트 수정 및 에러 핸들링 개선
- **결과**: 정상적인 AI 응답 생성
