## 🐛 해결된 주요 문제

### 1. 버튼 클릭 문제
- **문제**: 하단 메뉴 버튼들이 클릭되지 않음
- **원인**: GestureDetector가 전체 body를 감싸서 터치 이벤트 차단
- **해결**: Stack 구조 개선 및 Material + InkWell 적용

### 2. STT/TTS 무한 회귀
- **문제**: AI 응답을 STT가 다시 입력받는 현상
- **원인**: TTS 재생 중 STT 비활성화 로직 부족
- **해결**: _isTtsPlaying 상태 관리 및 콜백 시스템 구축

### 3. 알림 다이얼로그 닫기 문제
- **문제**: 다이얼로그가 닫히지 않는 현상
- **원인**: Consumer 내부에서 addPostFrameCallback 사용
- **해결**: 리스너 구조 개선 및 상태 추적 시스템 구축

### 4. 네트워크 시각화 분리 문제
- **문제**: 노드와 엣지가 좌우로 분리되어 표시
- **원인**: 좌표 계산 오류
- **해결**: Positioned 위젯과 NetworkPainter 좌표 동기화
