
- 🔌 **실시간 연결 관리**: 연결 상태 표시, 자동 재연결
- 📨 **알림 송수신**: REST API를 통한 알림 전송, WebSocket으로 실시간 수신
- 📊 **실시간 로그**: 모든 이벤트의 실시간 로그 표시

### 사용 방법
1. 브라우저에서 `notification_client.html` 파일 열기
2. 서버 URL: `ws://localhost` 입력
3. 사용자 ID 입력 (자동 생성됨)
4. "연결" 버튼 클릭
5. 알림 전송 테스트 또는 다른 클라이언트로부터 수신 확인
